# 03 — Cloud

This roadmap starts with AWS because it provides a broad platform for DevOps and cloud-security practice. Azure and GCP concepts are added through comparison rather than memorizing three clouds at once.

## 🟢 Beginner

### Cloud concepts
- IaaS, PaaS, SaaS
- Regions and availability zones
- Shared responsibility
- Elasticity and scalability
- High availability
- Basic cloud networking

### AWS core
- IAM
- VPC
- Subnets
- Route tables
- Internet/NAT gateways
- Security groups and network ACLs
- EC2
- S3
- RDS
- Load Balancers
- Auto Scaling
- Route 53
- CloudWatch

## ⚫ Interview focus

- Explain VPC architecture.
- Public vs private subnet.
- Security group vs NACL.
- NAT Gateway vs Internet Gateway.
- IAM role vs user.
- How would you secure a production AWS account?
- How would you design highly available web infrastructure?
- How would you detect and respond to compromised credentials?
