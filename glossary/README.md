# Glossary

A quick reference for terms that appear repeatedly throughout the roadmap.

| Term | Meaning |
|---|---|
| AZ | Availability Zone, an isolated location within a cloud region |
| CNI | Container Network Interface |
| CSI | Container Storage Interface |
| CSPM | Cloud Security Posture Management |
| DAST | Dynamic Application Security Testing |
| GitOps | Managing desired infrastructure/application state through Git and reconciliation |
| IaC | Infrastructure as Code |
| IDP | Internal Developer Platform |
| OPA | Open Policy Agent |
| PSS | Kubernetes Pod Security Standards |
| RBAC | Role-Based Access Control |
| SAST | Static Application Security Testing |
| SBOM | Software Bill of Materials |
| SCA | Software Composition Analysis |
| SLO | Service Level Objective |
| SLA | Service Level Agreement |
| SLI | Service Level Indicator |
| RTO | Recovery Time Objective |
| RPO | Recovery Point Objective |
| SCP | AWS Organizations Service Control Policy |
| Zero Trust | Security model based on explicit verification and least-privilege access rather than implicit network trust |

## Acronyms worth knowing

Before memorizing a tool, understand the problem represented by its acronym. For example, knowing that SBOM means Software Bill of Materials is less useful than understanding why dependency visibility matters during vulnerability response.
