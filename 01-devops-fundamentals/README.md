# 01 — DevOps Fundamentals

## 💡 What is DevOps?

DevOps is a set of engineering practices that improves collaboration and automation across software development and operations, with fast feedback and reliable delivery as major goals.

## 🟢 Beginner

- SDLC
- Dev vs Ops
- CI, CD and continuous deployment
- Version control
- Build and test automation
- Artifact management
- Environment separation
- Configuration management

## 🟡 Intermediate

- Pipeline as code
- Deployment strategies
- Release management
- Infrastructure automation
- Immutable artifacts
- Environment promotion
- Rollback strategies

## 🔴 Advanced

- Progressive delivery
- Reliability engineering
- Platform engineering
- Developer experience
- Policy and governance
- Supply-chain security

## 🛠️ Lab

Build a pipeline:

```text
Commit → Build → Test → Scan → Package → Publish → Deploy → Verify
```

Document what happens when each stage fails.
