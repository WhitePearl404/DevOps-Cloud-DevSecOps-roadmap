## 🧪 Labs

Prioritize hands-on environments that let you create, break and rebuild infrastructure:

- AWS free-tier-eligible resources where applicable
- Kubernetes local clusters
- Docker
- GitHub Actions
- Cloud-native project tutorials
- Security-focused labs

Always check current pricing before creating cloud resources.

## 🎓 Certification direction

Certifications should validate a skill path, not replace hands-on practice.

Suggested progression:

1. Cloud fundamentals
2. AWS associate-level architecture/operations or security track
3. Kubernetes-focused certification when Kubernetes fundamentals are strong
4. Security certification after practical cloud-security experience

## Source quality rule

Prefer:

**Official documentation → official labs → standards/specifications → reputable technical publications → community discussions → random tutorial at 2 AM.**
