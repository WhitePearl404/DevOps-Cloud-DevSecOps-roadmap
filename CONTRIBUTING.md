# Contributing

This repository is an educational roadmap and handbook.

## Good contributions

- Correct technical explanations
- Beginner-friendly examples
- Production-safe labs
- Troubleshooting guides
- Architecture diagrams
- Interview questions with accurate answers
- Updated technology references

## Standards

- Prefer official documentation.
- Explain prerequisites.
- Distinguish beginner, intermediate and advanced material.
- Never publish credentials, tokens or private infrastructure details.
- Include cleanup instructions for cloud labs.
- Avoid presenting emerging tools as established standards without evidence.

## Topic template

```markdown
# Topic

## 💡 What is it?
## 🎯 Why use it?
## 🧠 Core concepts
## 🔵 Architecture
## 🟢 Beginner
## 🟡 Intermediate
## 🔴 Advanced
## 🟣 Security

## 🚨 Troubleshooting

## 📚 Resources
```
