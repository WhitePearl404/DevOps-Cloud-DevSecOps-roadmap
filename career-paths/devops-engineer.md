# ⚙️ DevOps Engineer

## Focus

Automate the path from source code to reliable production workloads.

## Learning path

### Foundation
- Linux
- Networking
- Git
- Bash/Python
- DevOps principles

### Core
- Docker and OCI images
- GitHub Actions or another CI platform
- Terraform/OpenTofu
- AWS fundamentals
- Artifact and container registries
- Kubernetes
- Helm
- Argo CD or Flux

### Advanced
- Progressive delivery
- Deployment strategies
- GitOps at scale
- Observability
- SLOs and reliability
- Supply-chain security
- Infrastructure testing
- Platform automation

## Portfolio evidence

Build a complete CI/CD and GitOps pipeline that provisions infrastructure, tests code, scans artifacts, deploys to Kubernetes and provides observable rollback and recovery.

## Interview focus

- CI/CD design
- GitOps
- Terraform state and modules
- Kubernetes deployment failures
- Deployment strategies
- Secrets management
- Reliability and rollback
- Pipeline security
