# ☁️ Cloud Engineer

## Focus

Design, deploy and operate reliable cloud infrastructure.

## Learning path

### Foundation
- Linux administration
- TCP/IP, DNS, HTTP/HTTPS
- Git
- Bash or Python

### Core
- AWS IAM
- VPC, subnets, routing and security groups
- EC2
- S3
- RDS
- Load balancers
- Auto Scaling
- Route 53
- CloudFront
- CloudWatch
- Terraform/OpenTofu
- CI/CD

### Advanced
- Multi-account AWS
- Transit Gateway
- Private connectivity
- High availability and disaster recovery
- IAM least privilege
- KMS and secrets management
- Cost optimization
- Infrastructure policy and security scanning

## Portfolio evidence

Build an AWS environment with Terraform, secure networking, IAM, automated deployment, monitoring, failure testing and documented recovery procedures.

## Interview focus

- VPC and routing
- IAM design
- HA architecture
- Infrastructure as Code
- Security groups vs network ACLs
- Cost and reliability trade-offs
- Troubleshooting connectivity and failed deployments
