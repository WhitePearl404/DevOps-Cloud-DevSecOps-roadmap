# 🛡️ DevSecOps Engineer

## Focus

Integrate security into software delivery without turning every deployment into a committee meeting.

## Learning path

### Foundation
- Linux
- Networking
- Git
- Secure coding fundamentals
- DevOps lifecycle

### Core
- GitHub Actions or equivalent CI/CD
- SAST
- SCA
- Secrets scanning with Gitleaks
- IaC scanning with Checkov
- Container scanning with Trivy
- DAST fundamentals
- SBOM with Syft
- Vulnerability analysis with Grype
- Image signing with Cosign/Sigstore

### Advanced
- Provenance and SLSA concepts
- Policy-as-code
- Admission control
- Kubernetes security
- Runtime detection
- Security gates and exception management
- Vulnerability lifecycle management
- Threat modeling

## Portfolio evidence

Build a secure software supply chain that produces an SBOM, scans source and infrastructure, signs images, verifies artifacts and enforces security policies before deployment.

## Interview focus

- SAST vs SCA vs DAST
- False positives and risk-based gates
- SBOM lifecycle
- Image signing and verification
- Supply-chain attacks
- Secrets exposure
- Kubernetes admission controls
- Vulnerability remediation strategy
